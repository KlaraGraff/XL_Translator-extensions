# packages

Translator 项目自己维护的扩展（`status: official`）的安装包，由 Translator 的 `translator-sidecar adapter pack` 打出。其他扩展的安装包放在作者自己的仓库里。

Packages of the extensions maintained by the Translator project (`status: official`), built with Translator's `translator-sidecar adapter pack`. Other extensions keep their packages in their authors' repositories.
